# fruit-classification-naive-bayes
A supervised machine learning project that classifies fruits using Gaussian Naive Bayes. Includes data preprocessing, visualization, model training and performance evaluation.
# Fruit Classification using Gaussian Naive Bayes 🍎

## 📌 Project Overview
This project implements a supervised machine learning model to classify fruits based on physical features such as mass, width, height, and color score.

## 🎯 Objective
To build a classification model using Gaussian Naive Bayes algorithm.

## 🧠 Algorithm Used
- Gaussian Naive Bayes

## 📊 Features Used
- Mass
- Width
- Height
- Color Score

## ⚙️ Steps Included
- Data Preprocessing
- Data Visualization
- Model Training
- Model Testing
- Model Evaluation

## 📈 Evaluation Metrics
- Accuracy
- Confusion Matrix
- Classification Report

## 🗂 Dataset
The dataset is defined inside the Python file for demonstration purposes.

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🚀 How to Run
1. Install required libraries
2. Run the Python file:
   python fruit_classification.py
